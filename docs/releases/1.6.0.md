# Duewise 1.6.0

- Duplicate any active or archived reminder from its details screen.
- Opens a new draft containing name, category, date, time, repeat schedule, priority, enabled alerts, notes, and cost. Review and save to create a separate active reminder.
- Copies use fresh notification IDs and history. Attachments remain on the source. Temporary snoozes and disabled alerts are excluded.
- Leaving the unsaved copy uses the existing discard guard. Missing source records cannot be saved.

Validation on device: duplicate an active and archived reminder, change the copy date, save, verify the original stays unchanged, verify cost and alerts, and discard another copy.
