# Duewise 1.8.0

- Home links to a dedicated Cost breakdown screen, including when no recurring costs exist.
- Review active cost-bearing reminders by due date, filter by currency, and open details to edit.
- Includes free and one-time costs in the list; recurring estimates exclude one-time and archived items.
- Estimates remain separate per currency with monthly/yearly totals. A removed currency selection falls back to all currencies.
- Loading, empty, and error states are provided; reminders use a virtualized list.

Device checks: open from Home, inspect mixed currencies, tap a reminder to edit cost, return and confirm totals update, archive the last reminder in the selected currency, test empty state, large text and dark mode.
