# Duewise 1.4.0

## Document attachments

Add PDFs, JPEGs, PNGs, WebP or HEIC images from the Attachments section in reminder details, including archived reminders. Each reminder holds up to five files; each file may be at most 5 MB. Total attachment storage is limited to 25 MB across the app to bound backup and file-processing memory usage.

Picked files are copied into the app's private SQLite database. Moving or deleting the original file does not remove the attachment. Open / share hands a cached copy to the system share sheet, where compatible apps can open or receive it. Sharing is explicit; the app does not upload attachments itself.

Remove deletes the attachment from Duewise without modifying the original file. Permanently deleting a reminder cascades to its attachment records. Archiving and completing a reminder keep its documents. Shared copies in other apps are independent; app-cache copies may remain until removed or evicted by the OS. This feature does not promise secure erasure or encryption.

## Backups and migration

New backups use format version 2 and embed attachments. Duewise 1.4.0 accepts versions 1 and 2; older app versions cannot restore version 2. Backup files now allow up to 50 MB. They are unencrypted, including document contents. Save them privately.

Restore validates attachment data before importing and includes attachment rows in the same transaction as their reminder. Duplicate matching includes attachments; modified documents may cause a reminder to be imported as a separate copy. A restore that exceeds the 25 MB attachment budget is rejected before writing any imported records.

The schema migration adds a separate attachments table with cascading owner references; existing reminders remain unchanged. App/package/lock versions and the Settings fallback use 1.4.0. EAS build numbers still auto-increment. The added sharing module requires a new native build.

## Device checks

1. Install a new APK/IPA and verify Settings reports 1.4.0. Upgrade a populated 1.3.0 database and check existing reminders.
2. Attach a PDF and images on Android and iOS, including from a cloud file provider. Restart Duewise and confirm the documents remain after deleting the original file.
3. Cancel the picker. Reject empty, unsupported, oversized and sixth attachments without adding records. Check the total storage budget message.
4. Open/share a document using compatible apps. Remove it with confirmation and verify the original remains intact.
5. Archive/restore/complete a reminder and verify attachments remain. Permanently delete it and verify document records disappear.
6. Export a version 2 backup, restore onto a fresh installation, and open the restored documents. Verify duplicate imports are skipped and old version 1 backups still restore.
7. Reject invalid backup attachment payloads and over-budget restores with no partial imports.
8. Test large text, dark mode, missing sharing support and permission/cancellation behavior on a new binary. File picking and sharing still require physical-device verification.

Build an Android preview APK with `npx eas-cli@latest build --platform android --profile preview`. No native build has been submitted by this change.
