# Duewise 1.9.1

- Explicitly select development, preview, and production EAS environments for their matching build profiles.
- Cloud-enabled native builds require EXPO_PUBLIC_SUPABASE_URL and EXPO_PUBLIC_SUPABASE_PUBLISHABLE_KEY in the selected EAS environment. A local .env.local file does not configure remote builds.
- Rebuild and install after updating EAS variables; reopening an already-built app cannot change bundled configuration.
