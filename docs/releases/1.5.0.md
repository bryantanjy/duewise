# Duewise 1.5.0

- Optional cost per occurrence with MYR, USD, SGD, EUR, GBP, AUD, and CAD on create/edit forms and reminder details.
- Home shows monthly/yearly recurring estimates grouped by currency. Archived and one-time reminders are excluded; day/week/custom schedules use a 365-day year.
- Costs use integer minor units. Blank removes a cost; zero is supported.
- Backup format 3 preserves costs and attachments; versions 1 and 2 remain importable. Earlier apps must update before importing format 3.
- Existing reminders migrate with no cost assigned. Native build numbers continue to auto-increment through EAS.

Device checks: create/edit/clear a cost, verify mixed-currency totals, archive/restore, renew without losing cost, and export/restore a backup.
